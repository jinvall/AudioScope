# Phase 05 — User Interface

## Objective

Connect the working backend to a usable desktop interface.

## Tasks

Implement:

- main window
- waveform
- spectrogram
- event list
- event timeline
- event details
- playback controls
- separation query
- separation status
- separation results
- manual waveform selection
- system status

---

## Manual Workflow

The user must be able to:

1. Drag-select audio.
2. Enter a query.
3. Start separation.
4. Wait without freezing the UI.
5. Receive result.
6. Play result.
7. Save result.

---

## Acceptance

All visible buttons must perform real operations.

No placeholder UI actions.
