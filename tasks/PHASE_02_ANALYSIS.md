# Phase 02 — Analysis

## Objective

Create inexpensive continuous acoustic analysis.

## Tasks

Implement:

- RMS
- peak
- crest factor
- zero-crossing rate
- FFT
- spectral centroid
- bandwidth
- rolloff
- flatness
- spectral flux
- band energies
- adaptive noise floor

Create live analysis output.

Add waveform and spectrogram support.

---

## Acceptance

The system must continuously calculate features without blocking audio capture.

CPU usage should remain reasonable.

No neural source separation belongs in this phase.
