# OVERVIEW — SRP Theme Pack

This theme pack is structured for portability and fast integration:

- **Design Tokens:** consistent color/spacing/radius/shadow variables
- **Component Primitives:** cards, buttons, inputs, topbar, badges
- **Brand Assets:** logo and backgrounds copied from original source pack
- **Optional Runtime Helper:** light/dark toggle with persisted preference

## Intended Use

- Web dashboards
- Landing pages
- Internal tools
- Electron/Tauri web UIs

## Non-goals (v1)

- No SCSS build pipeline required
- No framework lock-in (works with plain HTML/CSS/JS)
- No dependency on npm packages
